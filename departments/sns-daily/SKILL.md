# 毎日のSNS投稿案

マーケティング部（`marketing-hq`）の定常業務。コマンドは次の2つを使う。

```
node "$HOME/.claude/skills/marketing-hq/scripts/growth.mjs" <コマンド>
node "$HOME/.claude/skills/secretary/scripts/secretary.mjs" <コマンド>
```

**定期実行（ユーザーがいない状態）で動いているときは質問しない。** 足りない情報があれば、何が足りないかを報告して終える。

## 手順

1. `secretary.mjs status` と `growth.mjs app list` を実行する。
   - 未初期化・マーケティング部なし・アプリ未登録なら、「marketing-hq でアプリを登録してください」と伝えて終える。
   - アプリが複数あり、指定がなければ、会話中なら聞く。定期実行ならプロンプトで指定されたアプリ、指定がなければ全アプリを1本ずつにする。
2. アプリのファイル（`app list` の `file`）を読む。`unfilledSections` が多く、ターゲットや悩みが空なら、質の低い案になる旨を伝え、埋めるよう促す（案は作ってよい）。
3. 材料を集める。
   - `growth.mjs post summary --app <ID> --days 30`：効いた形式・フック（ページ訪問・インストールにつながったものを重視）
   - `departments/research/topics/reviews/` の最新のレビュー分析（あれば）：ユーザーの悩みの言葉
   - `departments/marketing/content/` の直近の投稿案（同じネタのくり返しを避ける）
4. 投稿案を作る（指定がなければ **3本**）。`social` スキルの短尺動画・カルーセルの考え方に従う。
   - **2本は実績のある型の応用、1本は新しい型の実験**にする。実績がまだなければ、型を変えて3本試す。
   - 型の例: 悩み→解決の画面録画／スライド「〇〇な人がやるべき5つ」／作ってみた開発ストーリー／使用前・使用後／あるあるネタ
   - **アプリが公開前（`stage: prelaunch`）なら**、アプリの宣伝ではなく「共感とファンづくり」を中心にする。型の例: 開発の裏側・進捗（Build in Public）／ターゲットの悩みへの共感・あるある／機能のチラ見せ／名前・アイコン・機能の投票（コメントを集める）／ベータテスター募集／公開までのカウントダウン。CTA はフォロー・ベータ参加・事前登録にする。
   - 日本の視聴者に自然な日本語で書く。誇大表現・架空の体験談は使わない。
   - **他社のアプリ名・サービス名を使わない**。対象はフック・本文・キャプション・画像の文字・ハッシュタグ・音声のすべてで、「〇〇版」「〇〇風」「〇〇みたいな」の言い方も含む。例えば「ペット版 BeReal」は「毎日決まった時間にお題が届く」、「家族LINE」は「家族のグループチャット」のように、自分のアプリの仕組みや、ユーザーの状況の言葉で言い換える。
     - 理由: 有名な名前にただ乗りしていると見られる。比べられた側を下げる表現になりやすい。運営元から指摘されることがある。自分のアプリが「〇〇の二番煎じ」として覚えられ、その名前を知らない人（親世代など）には伝わらない。仕様が変わると、たとえが事実と合わなくなる。
     - 例外: 招待を送れる先（「LINE で招待を送れる」など）のように、事実として連携先を中立に説明する場合だけ使ってよい。他社のロゴや実在アプリの画面は使わない。
   - **音楽は商用利用できるものだけにする**。アプリの宣伝の投稿は仕事の目的になるので、TikTok は商用音楽ライブラリ、Instagram は「商用利用可」の音源を使う。自分の声・読み上げ・アプリの音でもよい。「トレンドの曲」は指定しない。
   - 書く前に、案の中の事実がアプリの今の状態と合っているかを確かめる。例えば「審査に出しました」「直しました」は、PM のマイルストーンで完了になっているときだけ書く。
5. 次の形式で `departments/marketing/content/YYYY-MM-DD-sns.md` に保存する（Write ツール。すでにあれば末尾に `## 追加（HH:MM）` として追記）。

```
# SNS投稿案 YYYY-MM-DD（<アプリ名>）

## 1. <一言タイトル>（<チャネル> / <形式> / 実績型の応用 or 実験）
- **フック（最初の1〜2秒）**: 画面の文字「…」／話す言葉「…」
- **構成**: 0-2秒 … / 2-8秒 … / 8-15秒 …（スライドなら1枚目〜）
- **撮る画面・素材**: …
- **キャプション**: …
- **ハッシュタグ**: #… #…（3〜5個）
- **CTA**: プロフィールのリンクから… など
- **狙い（仮説）**: なぜ伸びると考えるか
```

6. `secretary.mjs todo add "SNS投稿: <アプリ名>（案: content/YYYY-MM-DD-sns.md）"` を実行する（同じ内容は自動で重複しない）。
7. ユーザーに、3本の要点（フックと形式）を短く伝え、最後に「投稿したら『1番を投稿した』と教えてください。計測リンクを発行して記録します」と添える。

## 投稿したと言われたら

`marketing-hq` の手順で `growth.mjs post add --app <ID> --channel <チャネル> --format <形式> --hook "<フック>"` を実行し、計測リンクを伝える。
