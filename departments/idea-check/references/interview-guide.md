# 段階1: 5人に話を聞く

## 誰に聞くか

- 悩みを持っていそうな人。家族や親しい友人は、気をつかって良いことを言いがちなので、知り合いの知り合いくらいがよい。
- 5人で十分。同じ話が3人から出たら、それは本物の可能性が高い。
- 1人15〜20分。対面・通話・チャットのどれでもよい。

## 募集の文（例）

```
〇〇で困ったことがある人に、15分だけ話を聞かせてほしいです。
アプリを作る前に、本当に困っていることを知りたくて。
売り込みはしません。お礼に◯◯を（あれば）。
```

## 聞き方の決まり

1. **未来ではなく、過去を聞く。** 「使いますか？」「欲しいですか？」は聞かない（みんな「いいね」と言う）。「最後に〜したのはいつ？」「そのときどうした？」と、実際にあったことを聞く。
2. **自分の案を先に話さない。** 話すと、相手は案に合わせてしまう。案を見せるのは最後か、段階2で。
3. **数・頻度・お金・手間を具体的に聞く。** 「よくある」ではなく「先月は何回？」。
4. **沈黙を怖がらない。** 相手が考えている間は待つ。
5. **相手の言葉をそのままメモする。** これがあとでフックや説明文の材料になる。

## 質問の型

| 聞くこと | 質問の例 |
|---|---|
| 最近の具体的な場面 | 「最後に〇〇で困ったのはいつですか？　そのときのことを教えてください」 |
| そのときどうしたか | 「そのとき、どうやって解決しましたか？　何を使いましたか？」 |
| 手間・お金 | 「それにどのくらい時間がかかりましたか？　お金を払っているものはありますか？」 |
| 頻度 | 「その場面は、月に何回くらいありますか？」 |
| 今の方法の不満 | 「今のやり方で、一番面倒なところはどこですか？」 |
| 探したか | 「解決する方法を探したことはありますか？　何を試して、なぜやめましたか？」 |
| 最後に（任意） | 「もし〇〇ができたら、今のやり方と何が変わりますか？」 |

## 合格の見方

- 5人中3人以上が、**今その悩みに手間かお金をかけている**（自分で工夫している、別のアプリを使っている、困って探したことがある）→ 悩みは本物。段階2へ。
- 「困ってはいるけど、特に何もしていない」が多い → 悩みが弱い。対象の人を変えるか、悩みを捉え直す。
- 話の中で、思っていたのと違う悩みが出てきたら、それを記録する（ピボットの種）。

## 記録

記録ファイルの「結果ログ」に、1人ずつ書く（名前は書かない）。

```
- 2026-10-05 段階1 Aさん（30代・猫2匹・一人暮らし）
  - 最後に困った場面: 「…」（相手の言葉）
  - 今のやり方: …
  - 手間・お金: …
  - 判定: 手間をかけている／いない
```
